# Конвертер валют

Flutter-приложение для конвертации валют по актуальным курсам. Курсы и время
обновления загружаются из бесплатного
[ExchangeRate-API](https://www.exchangerate-api.com/docs/free); ключ API не
требуется.

## Возможности

- Ввод суммы и выбор исходной и целевой валюты.
- Конвертация, в том числе EUR → RUB, и обмен валют местами.
- Отображение результата, курса и даты его обновления.
- Индикатор загрузки и понятные сообщения об ошибках сети или ввода.
- Избранные валюты с локальным сохранением; добавление и удаление доступно в
  окне выбора валюты.
- История последних 20 успешных конвертаций с локальным сохранением и
  возможностью очистки.
- Выбор валюты из списка с поиском.

Приложение построено по цепочке UI → `ConverterState` →
`CurrencyRepository` → `CurrencyApiClient`.

## Запуск и проверка

```sh
flutter pub get
flutter run
flutter test
```

Для загрузки курса требуется подключение к интернету. Суммы должны быть
положительными; в качестве десятичного разделителя принимается точка или
запятая.
